# AI Help Desk - ИИ-сервис поддержки пользователей

MVP-проект для хакатона ITFEST. Система автоматической обработки и маршрутизации обращений пользователей с использованием Gemini 2.5 Flash.

## Возможности

- ✅ Единый интеллектуальный вход для заявок из разных источников (портал, чат, email, телефон)
- ✅ Автоматическая обработка тикетов через AI (определение языка, категории, приоритета, типа)
- ✅ Автоматическое решение типовых инцидентов без участия операторов
- ✅ Умная маршрутизация по отделам
- ✅ Поддержка русского и казахского языков
- ✅ Веб-панель мониторинга для администраторов
- ✅ Помощь операторам с AI-подсказками и резюме

## Технологический стек

- **Backend**: Python 3 + Flask
- **База данных**: SQLite через SQLAlchemy
- **Frontend**: HTML + CSS + Vanilla JavaScript
- **AI**: Gemini 2.5 Flash (через HTTP API)

## Установка и запуск

### 1. Создайте виртуальное окружение

```bash
python -m venv venv
```

### 2. Активируйте виртуальное окружение

**Windows:**
```bash
venv\Scripts\activate
```

**Linux/Mac:**
```bash
source venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Настройте переменные окружения

Создайте файл `.env` в корне проекта (или отредактируйте существующий):

```env
# Flask Configuration
SECRET_KEY=your-secret-key-here-change-in-production
DATABASE_URL=sqlite:///helpdesk.db

# Gemini API Configuration
GEMINI_API_KEY=your-gemini-api-key-here
GEMINI_API_URL=https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash-exp:generateContent
```

**Важно:** Получите API ключ Gemini на [Google AI Studio](https://makersuite.google.com/app/apikey)

### 5. Запустите приложение

```bash
python app.py
```

Приложение будет доступно по адресу: `http://localhost:5000`

## Использование

### Создание обращения

1. Откройте главную страницу: `http://localhost:5000`
2. Выберите источник обращения (портал, чат, email, телефон)
3. Введите текст обращения (поддерживаются русский и казахский языки)
4. Нажмите "Отправить обращение"
5. Система автоматически обработает обращение и покажет результат

### Админ-панель

1. Откройте админ-панель: `http://localhost:5000/admin`
2. Просматривайте статистику по тикетам
3. Используйте фильтры для поиска нужных тикетов
4. Нажмите "Просмотр" для детального просмотра тикета
5. Редактируйте ответ оператора и статус тикета

## API Endpoints

### POST /api/tickets
Создание нового тикета

**Request:**
```json
{
  "text": "Текст обращения",
  "source": "portal"
}
```

**Response:**
```json
{
  "success": true,
  "ticket": {
    "id": 1,
    "text": "...",
    "status": "AUTO_CLOSED",
    "summary": "...",
    ...
  }
}
```

### GET /api/tickets
Получение списка тикетов

**Query params:**
- `status` - фильтр по статусу
- `department` - фильтр по отделу
- `source` - фильтр по источнику

### GET /api/tickets/<id>
Получение детальной информации о тикете

### PATCH /api/tickets/<id>
Обновление тикета

**Request:**
```json
{
  "status": "RESOLVED",
  "last_response": "Ответ оператора"
}
```

### GET /api/stats
Получение статистики по тикетам

## Особенности работы AI

- Автоматически определяет язык обращения (ru/kk)
- Категоризирует проблему (доступ, почта, сеть, ПО и т.д.)
- Определяет приоритет (LOW/MEDIUM/HIGH/CRITICAL)
- Классифицирует тип (INCIDENT/REQUEST/QUESTION/COMPLAINT)
- Назначает отдел (IT/Security/HR и т.д.)
- Генерирует автоответ для типовых вопросов
- Автоматически закрывает простые обращения

## Fallback режим

Если API ключ Gemini не задан или API недоступен, система работает в fallback режиме:
- Использует простые эвристики для категоризации
- Создает тикеты без AI-анализа
- Система продолжает работать, но без автоматической обработки
