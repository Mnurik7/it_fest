# HelpDesk - Платформа поддержки срочных запросов

HelpDesk - это комплексная платформа искусственного интеллекта для обработки срочных запросов в различных сферах, содержащая специализированные AI-модули для различных отраслей.

## Help Desk Модули

### Основные Help Desk модули:

1. **IT Help Desk** - Система поддержки для IT-запросов: техническая поддержка, решение проблем с оборудованием и программным обеспечением
2. **Medical Help Desk** - Поддержка медицинских запросов: помощь пациентам, запись на приём, консультации, экстренные обращения
3. **Legal Help Desk** - Юридическая поддержка: консультации, обработка правовых запросов, документооборот, срочные юридические вопросы
4. **Retail Help Desk** - Поддержка розничных клиентов: обработка жалоб, возвраты, консультации по товарам, поддержка продаж
5. **Telecom Help Desk** - Телекоммуникационная поддержка: проблемы с связью, интернетом, настройка оборудования, биллинг
6. **Auto Help Desk** - Автомобильная поддержка: техническая помощь, запись на сервис, консультации по ремонту, экстренная помощь

### Дополнительные AI Модули:

1. **AI-Procure** - AI-агент для закупок и тендерного анализа
2. **AI-Scrum Master** - Ассистент по управлению задач для сотрудников
3. **AI-Business Analyst** - AI-помощник по бизнес-аналитике
4. **AI-Code Review Assistant** - AI-агент для проведения ревью кода в GitLab
5. **Fraud Detection** - ML модель для детекции мошеннических транзакций

## Технологии

- **Backend**: Flask (Python)
- **Frontend**: HTML, CSS, JavaScript
- **AI**: Google Gemini API
- **База данных**: JSON для пользователей

## Установка

1. Убедитесь, что у вас установлен Python 3.8+

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` в корневой директории проекта (или скопируйте из примера):
```bash
# Windows PowerShell
Copy-Item .env.example .env

# Linux/Mac
cp .env.example .env
```

Затем откройте `.env` и добавьте ваш API ключ:
```
GEMINI_API_KEY=AIzaSyAz3tJhRYYXNhHSRGKmHtawXY6ZtucCKBE
GEMINI_MODEL=gemini-2.5-flash
GEMINI_API_VERSION=v1beta
```

**Примечание**: Если вы используете предоставленный API ключ, просто создайте файл `.env` вручную с указанными выше значениями.

### AI-Scrum Master - Особенности

AI-Scrum Master - это комплексный цифровой Scrum Master для управления проектами и задачами в банке.

#### Основные функции:

1. **📁 Управление проектами и командами**
   - Создание проектов
   - Формирование команд
   - Управление участниками и ролями
   - Отслеживание загрузки сотрудников

2. **✅ Создание задач из текста**
   - Автоматическое создание Epic, User Stories, Tasks из:
     - Технических заданий
     - Описаний проектов
     - Переписки
     - Транскриптов встреч
   - Определение приоритетов, зависимостей, дедлайнов
   - Автоматическое назначение исполнителей
   - Генерация критериев готовности (DoD)

3. **🧩 Интеллектуальная декомпозиция задач**
   - Логическое разбиение задач с учётом команды и ресурсов
   - Оптимизация распределения задач
   - Выявление узких мест
   - Предупреждения о перегрузке

4. **🤝 AI-ассистент встреч**
   - Анализ транскриптов (Stand-up, Grooming, Demo, Planning, Retrospective)
   - Выявление новых задач, проблем, зависимостей
   - Автоматическая генерация отчётов
   - Обновление статусов задач

5. **⏰ Контроль дедлайнов**
   - Отслеживание всех сроков
   - Напоминания (персональные, команде, менеджерам)
   - Выявление рисков срыва
   - История выполнения (в срок/с задержкой)

6. **🏃 Управление спринтами**
   - Автоматическое формирование Sprint Backlog
   - Burndown Chart и Velocity
   - Анализ производительности спринта
   - Выявление проблемных зон

7. **📊 Аналитика и AI-инсайты**
   - Отчёты по эффективности
   - Выявление проблемных зон и скрытых рисков
   - Прогноз выполнения спринта
   - Рекомендации по улучшению

8. **🔗 Интеграции**
   - Подготовка к интеграции с Jira (создание, обновление задач)
   - Подготовка к интеграции с Teams (анализ встреч)
   - Уведомления и логирование

#### API Endpoints:

**Проекты:**

- `GET /api/ai-scrum/projects` - Список проектов

### AI-Procure - Особенности

AI-Procure - это комплексный AI-агент для анализа тендеров и закупок с поддержкой новичков.

#### Основные функции:

1. **📋 Извлечение параметров тендера**
   - Автоматическое извлечение ключевых параметров из текста, PDF или веб-сайтов
   - Анализ полноты информации
   - Структурирование данных о заказчике, предмете закупки, бюджете, сроках

2. **🔍 Подбор поставщиков**
   - Интеллектуальный подбор релевантных поставщиков по критериям
   - Оценка релевантности и соответствия требованиям
   - Анализ сильных и слабых сторон поставщиков

3. **⚠️ Анализ рисков**
   - Выявление аффилированности компаний
   - Обнаружение подозрительных контрактов
   - Проверка прозрачности процесса
   - Анализ соответствия требованиям

4. **📄 Генерация отчётов**
   - Комплексные отчёты с анализом тендера
   - Обоснование выбора победителя
   - Рекомендации для всех участников процесса

5. **🎓 Поддержка новичков**
   - Пошаговые инструкции (10 шагов)
   - Песочница для тренировочных тендеров
   - Система рейтинга и опыта
   - Поиск партнёрств с опытными поставщиками
   - Автоматическая генерация документов

#### API Endpoints:

- `POST /api/ai-procure/extract` - Извлечение параметров тендера
- `POST /api/ai-procure/match-suppliers` - Подбор поставщиков
- `POST /api/ai-procure/analyze-risks` - Анализ рисков
- `POST /api/ai-procure/check-affiliation` - Проверка аффилированности
- `POST /api/ai-procure/generate-report` - Генерация отчёта
- `POST /api/ai-procure/analyze` - Комплексный анализ (все функции)
- `GET /api/ai-procure/beginner/rating` - Получение рейтинга новичка
- `POST /api/ai-procure/beginner/sandbox/create` - Создание тендера в песочнице
- `POST /api/ai-procure/beginner/guide` - Пошаговая инструкция
- `POST /api/ai-procure/beginner/partnerships` - Поиск партнёрств
- `POST /api/ai-procure/beginner/generate-documents` - Генерация документов

#### Метрики успеха:

- **Performance**: ≥90% корректно извлечённых данных, ≥80% подтверждённых случаев рисков
- **Бизнес-ценность**: Сокращение времени обработки, увеличение количества проанализированных тендеров
- **Usability**: Интуитивный интерфейс с выбором функциональности, поддержка новичков

### AI-Code Review Assistant - Особенности

AI-Code Review Assistant - это комплексный AI-агент для проведения ревью кода в GitLab, помогающий сеньор-разработчикам анализировать изменения в Merge Request.

#### Основные функции:

1. **📐 Загрузка архитектуры проекта**
   - Поддержка различных форматов: ZIP, PDF, PNG, JPG, DOCX, TXT, MD, JSON
   - AI анализирует архитектуру и выявляет потенциальные узкие места и проблемные зоны
   - Рекомендации по улучшению, масштабированию, выявлению опасений

2. **📄 Ревью отдельного файла**
   - Анализ кода на соответствие стандартам кодирования
   - Проверка архитектурных требований
   - Оценка корректности реализации функционала
   - Генерация рекомендаций по улучшению

3. **📁 Ревью всего проекта**
   - Комплексный анализ по архитектуре, затем по каждому файлу
   - Полные рекомендации по улучшению, масштабированию
   - Выявление опасений, плюсов и минусов
   - Анализ системных проблем и технического долга

4. **🔄 Анализ изменений (diff)**
   - Проверка на соответствие стандартам кодирования и архитектурным требованиям
   - Оценка корректности реализации функционала
   - Выявление потенциальных ошибок и регрессий
   - Рекомендации по улучшению

5. **🔀 Управление Merge Request**
   - Обновление статусов MR: ready-for-merge, needs-review, changes-requested, reject
   - Управление метками MR
   - Просмотр списка MR с фильтрацией
   - Интеграция с GitLab workflow

6. **📚 Обучающая поддержка**
   - Автоматические подсказки и объяснения для младших разработчиков
   - Интерактивные рекомендации по улучшению архитектуры и кода
   - Отслеживание прогресса разработчиков
   - Статистика по частым проблемам

#### API Endpoints:

**Архитектура:**
- `POST /api/ai-code-review/upload-architecture` - Загрузить и проанализировать архитектуру

**Анализ кода:**
- `POST /api/ai-code-review/analyze-code` - Анализ отдельного файла
- `POST /api/ai-code-review/analyze-diff` - Анализ diff изменений
- `POST /api/ai-code-review/analyze-project` - Анализ всего проекта

**Отчёты:**
- `POST /api/ai-code-review/generate-report` - Генерация итогового отчёта

**GitLab интеграция:**
- `POST /api/ai-code-review/mr/update-status` - Обновить статус MR
- `GET /api/ai-code-review/mr/<mr_id>` - Получить статус MR
- `GET /api/ai-code-review/mr/list` - Список MR

**Обучение:**

- `GET /api/ai-code-review/educational/stats/<developer_id>` - Статистика разработчика

  - Корректность выявления проблем по стандартам 100%

  - Рост эффективности команды: ускорение цикла принятия MR
- **Usability**:
