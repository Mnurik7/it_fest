# Текст для презентации проекта HelpDesk AI Platform

## Слайд 1: Титульный слайд

**HelpDesk AI Platform**  
*Комплексная платформа искусственного интеллекта для автоматизации поддержки и бизнес-процессов*

Разработано в рамках ITFEST Hackathon

---

## Слайд 2: Проблема

### Текущие вызовы организаций:

- **Высокая нагрузка на службы поддержки** - сотни обращений ежедневно требуют ручной обработки
- **Длительное время ответа** - клиенты ждут решения проблем часами и днями
- **Неэффективное распределение задач** - сложные кейсы попадают к неправильным специалистам
- **Ручная обработка документов** - бизнес-аналитики тратят дни на анализ требований
- **Недостаток экспертизы** - сложные задачи требуют привлечения сеньор-специалистов

### Цель проекта:

**Полная автоматизация первичной обработки запросов и интеллектуальная поддержка бизнес-процессов с помощью AI**

---

## Слайд 3: Решение - HelpDesk AI Platform

### Что мы создали:

**Единая интеллектуальная платформа**, объединяющая:

✅ **6 специализированных Help Desk модулей** для различных отраслей  
✅ **5 продвинутых AI-ассистентов** для автоматизации бизнес-процессов  
✅ **ML-модели для детекции мошенничества** с реальным временем обработки  
✅ **Telegram-бот** для круглосуточной поддержки клиентов  
✅ **Веб-интерфейсы** для операторов и администраторов

---

## Слайд 4: Архитектура платформы

### Компоненты системы:

```
┌─────────────────────────────────────────────────┐
│         HelpDesk AI Platform                    │
├─────────────────────────────────────────────────┤
│  Frontend: Flask Web App + Telegram Bot        │
│  Backend: Python Flask (8385+ строк кода)      │
│  AI Engine: Google Gemini 2.5 Flash            │
│  ML Models: XGBoost, LightGBM                  │
│  Data Storage: JSON, SQLite, файловое хранилище│
└─────────────────────────────────────────────────┘
```

**197 API эндпоинтов** для взаимодействия с модулями  
**21 HTML шаблон** для пользовательских интерфейсов  
**Модульная архитектура** - каждый компонент работает независимо

## Слайд 5: Help Desk модули - Отраслевые решения

### 6 специализированных модулей поддержки:

1. **IT Help Desk**  
   Техническая поддержка: решение проблем с оборудованием, ПО, настройками

2. **Medical Help Desk**  
   Медицинская поддержка: запись на приём, консультации, экстренные обращения

3. **Legal Help Desk**  
   Юридическая поддержка: консультации, обработка правовых запросов, документооборот

4. **Retail Help Desk**  
   Розничная поддержка: обработка жалоб, возвраты, консультации по товарам

5. **Telecom Help Desk**  
   Телекоммуникационная поддержка: проблемы со связью, интернетом, биллинг

6. **Auto Help Desk**  
   Автомобильная поддержка: техническая помощь, запись на сервис, консультации

### Возможности каждого модуля:
- Автоматическая классификация обращений
- Интеллектуальное определение приоритета
- Мгновенные ответы на типовые вопросы
- Автоматическая эскалация сложных кейсов
- История диалогов и контекстное понимание

## Слайд 6: AI-Procure - Ассистент для закупок

### Интеллектуальный анализ тендеров

**Основные функции:**

📋 **Извлечение параметров тендера**  
Автоматический анализ текста, PDF и веб-сайтов. Структурирование данных о заказчике, предмете закупки, бюджете и сроках.

🔍 **Подбор поставщиков**  
Интеллектуальный поиск релевантных поставщиков с оценкой соответствия требованиям и анализом сильных/слабых сторон.

⚠️ **Анализ рисков**  
Выявление аффилированности компаний, обнаружение подозрительных контрактов, проверка прозрачности процесса.

📄 **Генерация отчётов**  
Комплексные отчёты с анализом тендера, обоснованием выбора и рекомендациями для всех участников.

🎓 **Поддержка новичков**  
Пошаговые инструкции, песочница для тренировочных тендеров, система рейтинга и опыта, поиск партнёрств.

### Метрики успеха:
- **≥90%** корректно извлечённых данных
- **≥80%** подтверждённых случаев рисков
- Сокращение времени обработки тендеров

## Слайд 7: AI-Scrum Master - Цифровой Scrum Master

### Комплексное управление проектами и задачами

**8 ключевых функций:**

1. **📁 Управление проектами и командами**  
   Создание проектов, формирование команд, управление участниками и ролями

2. **✅ Создание задач из текста**  
   Автоматическое создание Epic, User Stories, Tasks из технических заданий, описаний проектов, переписки, транскриптов встреч

3. **🧩 Интеллектуальная декомпозиция**  
   Логическое разбиение задач с учётом команды и ресурсов, оптимизация распределения

4. **🤝 AI-ассистент встреч**  
   Анализ транскриптов (Stand-up, Grooming, Demo, Planning, Retrospective), выявление задач и проблем

5. **⏰ Контроль дедлайнов**  
   Отслеживание сроков, напоминания, выявление рисков срыва, история выполнения

6. **🏃 Управление спринтами**  
   Формирование Sprint Backlog, Burndown Chart, Velocity, анализ производительности

7. **📊 Аналитика и AI-инсайты**  
   Отчёты по эффективности, прогноз выполнения спринта, рекомендации по улучшению

8. **🔗 Интеграции**  
   Подготовка к интеграции с Jira, Teams, уведомления и логирование

### Результаты:
- Сокращение времени ревью на **≥50%**
- Ускорение цикла принятия MR
- Автоматизация рутинных операций Scrum Master

## Слайд 8: AI-Business Analyst - AI-помощник по бизнес-аналитике

### Автоматизация работы бизнес-аналитика

**Ключевые возможности:**

📄 **Анализ документов**  
Автоматический анализ BRD, технических заданий, требований. Извлечение структуры, выявление противоречий.

💬 **Структурированный диалог**  
Пошаговый сбор требований через умный диалог. Адаптация к стилю пользователя, понимание неформальных формулировок.

📝 **Генерация документов**  
Автоматическое создание BRD, FRD, Use Cases, User Stories, BPMN-диаграмм, лидирующих индикаторов.

📊 **Анализ процессов**  
Выявление узких мест, анализ эффективности, предложения по улучшению с расчётом ROI.

🔍 **Извлечение требований**  
Структурирование требований из неформального текста, валидация полноты и согласованности.

📈 **Метрики и отчётность**  
Отслеживание метрик производительности, бизнес-ценности и удобства использования.

### Особенности:
- Интеграция с Confluence для сохранения документов
- Автодополнение при вводе
- Умный анализ сообщений и контекста
- Поддержка множественных форматов документов

## Слайд 9: AI-Code Review Assistant - Ревью кода с AI

### Анализ кода для GitLab Merge Requests

**Основные функции:**

📐 **Загрузка архитектуры проекта**  
Поддержка ZIP, PDF, PNG, JPG, DOCX, TXT, MD, JSON. Анализ архитектуры, выявление узких мест и проблемных зон.

📄 **Ревью отдельного файла**  
Проверка соответствия стандартам кодирования, архитектурным требованиям, корректности реализации.

📁 **Ревью всего проекта**  
Комплексный анализ по архитектуре и каждому файлу. Выявление системных проблем и технического долга.

🔄 **Анализ изменений (diff)**  
Проверка соответствия стандартам, выявление потенциальных ошибок и регрессий.

🔀 **Управление Merge Request**  
Обновление статусов MR, управление метками, интеграция с GitLab workflow.

📚 **Обучающая поддержка**  
Автоматические подсказки для младших разработчиков, отслеживание прогресса, статистика по частым проблемам.

### Метрики успеха:
- **≥90%** релевантных рекомендаций
- Среднее время анализа MR **≤5 минут**
- **100%** корректность выявления проблем
- Снижение нагрузки сеньоров на **≥50%**

- `ml_models/` - ML модели для детекции мошенничества
- `procure_models/` - модули AI-Procure (18 файлов)
- `scrum_models/` - модули AI-Scrum Master (14 файлов)
- `business_analyst_models/` - модули AI-Business Analyst (8 файлов)
- `code_review_models/` - модули AI-Code Review (7 файлов)
- `templates/` - 21 HTML шаблон
- `static/` - CSS, JavaScript, изображения
- `data/` - JSON базы данных и кэш

**API эндпоинты:**
- Help Desk модули: 42 эндпоинта
- AI-Procure: 12 эндпоинтов
- AI-Scrum Master: 35 эндпоинтов
- AI-Business Analyst: 28 эндпоинтов
- AI-Code Review: 18 эндпоинтов
- Fraud Detection: 8 эндпоинтов
- Системные: 54 эндпоинта

**Установка и запуск:**
1. Установка зависимостей из `requirements.txt`
2. Настройка `.env` файла с API ключами
3. Запуск `python app.py`
4. Доступ через `http://localhost:5000`

## Рекомендации по презентации

### Временные рамки:

- **Слайды 1-5** (Проблема и решение): 3-4 минуты
- **Слайды 6-10** (Модули): 8-10 минут
- **Слайды 11-15** (Технологии и результаты): 5-6 минут
- **Слайды 16-20** (Преимущества и заключение): 3-4 минуты
- **Демонстрация**: 5-7 минут

**Общее время: 24-31 минута**

### Акценты:

1. Подчеркнуть **комплексность** решения
2. Показать **реальные результаты** и метрики
3. Демонстрировать **работоспособность** всех модулей
4. Выделить **уникальность** подхода
5. Показать **готовность к внедрению**

### Демонстрация:

Рекомендуется показать:
- Работу одного Help Desk модуля (например, IT)
- AI-Procure: анализ тендера
- AI-Scrum Master: создание задач
- AI-Business Analyst: генерация документа
- AI-Code Review: анализ кода
