Google Meet

Подключение к звонкам и автоматическая транскрибация

⚪ Не настроено
⚠️ Требуется установка библиотек

Для работы Google Meet интеграции необходимо установить библиотеки Python.

pip install google-auth google-auth-oauthlib google-auth-httplib2 google-api-python-client

Или используйте скрипт: install_dependencies.bat

📖 Как использовать Google Meet интеграцию
🔧 Быстрая настройка (2 шага)
1️⃣ Получите ключи в Google Cloud Console
• Откройте Google Cloud Console
• Включите Google Meet API (APIs & Services → Library → "Google Meet API" → Enable)
• Настройте OAuth consent screen (APIs & Services → OAuth consent screen → выберите "External" или "Internal")
• Создайте OAuth 2.0 Client ID (APIs & Services → Credentials → "+ CREATE CREDENTIALS" → "OAuth client ID" → "Web application")
• Добавьте Redirect URI: http://localhost:5000/api/ai-scrum/integrations/google-meet/callback
• Важно: Если приложение в режиме тестирования, добавьте тестовых пользователей в OAuth consent screen → Test users
• Скопируйте Client ID и Client Secret
2️⃣ Введите данные в форму ниже
• Вставьте Client ID и Client Secret в поля ниже
• Нажмите "Тестировать подключение" → "Сохранить настройки"
• Готово! Теперь можно запускать встречи с AI-ассистентом
✨ Что умеет интеграция:
✓ Автоматическая транскрибация встреч
✓ AI задаёт уточняющие вопросы во время звонка
✓ AI отвечает на вопросы участников в реальном времени
⚠️ Важно: Тестовые пользователи
Если приложение в режиме тестирования, добавьте email пользователей в OAuth consent screen → Test users.
Иначе при авторизации будет ошибка "Доступ заблокирован".
