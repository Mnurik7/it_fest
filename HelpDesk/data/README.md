# Директория данных ForteAI

Эта директория содержит все данные, создаваемые модулями системы ForteAI.

## Структура файлов

### AI-Scrum Master

#### `scrum_projects.json`
Содержит информацию о проектах:
- ID проекта
- Название и описание
- Владелец
- Статус
- Дедлайн
- Участники команды
- Список спринтов

#### `scrum_tasks.json`
**Главный файл для хранения всех задач!**

Содержит все созданные задачи:
- **Epic** (тип: "epic") - крупные бизнес-инициативы
- **User Stories** (тип: "user_story") - пользовательские истории
- **Tasks** (тип: "development", "testing", "design", etc.) - конкретные задачи
- **Subtasks** (тип: "subtask") - подзадачи

**Структура задачи:**
```json
{
  "task_id": "TASK-1",
  "project_id": "PROJ-20251128014105",
  "title": "Название задачи",
  "description": "Описание",
  "type": "development",
  "priority": "high",
  "status": "planned",
  "story_points": 5,
  "estimated_hours": 20,
  "complexity": "medium",
  "assignee": "username",
  "deadline": "2025-12-01",
  "dependencies": ["TASK-2"],
  "definition_of_done": ["Критерий 1", "Критерий 2"],
  "created_at": "2025-11-28T01:58:55"
}
```

#### `scrum_sprints.json`
Содержит информацию о спринтах:
- ID спринта
- Проект
- Название и цель
- Даты начала и окончания
- Статус
- Список задач в спринте

#### `scrum_teams.json`
Содержит информацию о командах проектов

#### `scrum_members.json`
Содержит информацию об участниках команд:
- ID участника
- Проект
- Имя пользователя
- Роль
- Загрузка
- Активные задачи

#### `scrum_deadlines.json`
Содержит информацию о дедлайнах задач

#### `scrum_deadline_history.json`
История выполнения дедлайнов

#### `scrum_meetings.json`
**Главный файл для хранения всех проанализированных встреч!**

Содержит результаты анализа встреч:
- Stand-up
- Grooming
- Demo
- Planning
- Retrospective

**Структура встречи:**
```json
{
  "meeting_id": "MEET-20251128015855",
  "project_id": "PROJ-20251128014105",
  "meeting_summary": {
    "type": "standup",
    "date": "2025-11-28T01:58:55",
    "participants": ["Иван", "Мария"],
    "duration_minutes": 15,
    "key_topics": ["тема 1", "тема 2"]
  },
  "new_tasks": [...],
  "updated_tasks": [...],
  "problems_identified": [...],
  "meeting_report": {...},
  "analyzed_at": "2025-11-28T01:58:55"
}
```

### AI-Procure

#### `beginner_ratings.json`

#### `sandbox_tenders.json`
Тренировочные тендеры в песочнице

### Общие

#### `users.json`
База данных пользователей системы

## Где сохраняются задачи?

**Все задачи сохраняются в файл: `data/scrum_tasks.json`**

При создании задач из текста:
1. AI анализирует текст и создаёт структуру (Epic, User Stories, Tasks, Subtasks)
2. При нажатии "Подтвердить и сохранить" все задачи записываются в `scrum_tasks.json`
3. Каждая задача получает:
   - Уникальный `task_id`
   - `project_id` для связи с проектом
   - Все параметры (приоритет, сложность, дедлайн, исполнитель и т.д.)
   - Статус по умолчанию: "planned"

## Формат хранения

Все файлы используют формат JSON с кодировкой UTF-8 для поддержки кириллицы.

## Резервное копирование

Рекомендуется регулярно создавать резервные копии директории `data/` для сохранности данных.
