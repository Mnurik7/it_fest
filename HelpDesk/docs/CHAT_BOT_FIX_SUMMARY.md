# Исправление проблемы с чат-ботом

## Проблема
Чат-бот застревал на одном этапе и повторял один и тот же вопрос вместо перехода к следующему.

**Пример проблемы:**
```
Пользователь: Создать безумный дизайн
Бот: Понятно, спасибо!
Бот: Отлично! Теперь расскажите, какова основная цель вашего проекта? (повтор)
```

## Исправления

### 1. Упрощена структура этапов
- Удален дублирующий этап PROJECT_NAME
- Название проекта теперь собирается сразу на INITIAL этапе
- После INITIAL сразу переходим к PROJECT_GOAL

### 2. Улучшена логика перехода между этапами
- Исправлена проверка достаточности данных
- Снижены требования к длине ответа (3 символа для INITIAL, 5 для других)
- Добавлена автоматическая проверка готовности к REVIEW

### 3. Исправлена обработка ответов
- Первый ответ пользователя корректно сохраняется как название проекта
- Данные извлекаются перед переходом к следующему этапу
- Этап обновляется только при успешном переходе

## Порядок работы диалога теперь:

1. **INITIAL**: "Как называется ваш проект?"
   - Пользователь отвечает: "Создать безумный дизайн"
   - Сохраняется как `project_name`
   - Переход к следующему этапу

2. **PROJECT_GOAL**: "Какова цель проекта?"
   - Пользователь отвечает
   - Переход к следующему этапу

3. И так далее по этапам...

## Результат

Теперь бот:
- ✅ Правильно переходит между этапами
- ✅ Не повторяет вопросы
- ✅ Корректно сохраняет данные на каждом этапе
- ✅ Автоматически переходит к генерации документов после завершения
