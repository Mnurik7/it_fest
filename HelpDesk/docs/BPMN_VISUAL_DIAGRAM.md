# Визуальная диаграмма BPMN

## ✅ Что реализовано

### 1. Визуальная диаграмма вместо текста
- ✅ SVG-диаграмма с элементами BPMN
- ✅ Автоматическое позиционирование элементов
- ✅ Цветовая кодировка элементов
- ✅ Стрелки и связи между элементами

### 2. Типы элементов BPMN

#### Start Event (Стартовое событие):
- Зеленый круг
- Обозначает начало процесса

#### Tasks (Задачи):
- Синие прямоугольники с закругленными углами
- Содержат название задачи

#### Gateways (Шлюзы):
- Желтые ромбы
- Обозначают точки принятия решений

#### End Events (Конечные события):
- Красные круги с толстой обводкой
- Обозначают конец процесса

#### Sequence Flows (Потоки):
- Стрелки между элементами
- Могут содержать метки условий

### 3. Функциональность

- ✅ Автоматическая генерация структурированных данных процесса
- ✅ Визуализация процесса в SVG
- ✅ Скачивание диаграммы как SVG файл
- ✅ Модальное окно с полноразмерной диаграммой

## 🎯 Как это работает

### Шаг 1: Генерация BPMN
1. Нажмите кнопку "Генерация BPMN"
2. Введите описание бизнес-процесса
3. Система генерирует структурированные данные

### Шаг 2: Визуализация
1. AI создает структуру процесса (задачи, шлюзы, события)
2. Элементы автоматически позиционируются
3. Связи между элементами отрисовываются стрелками
4. Диаграмма отображается в модальном окне

### Шаг 3: Использование
1. Просмотр диаграммы в полноразмерном окне
2. Скачивание диаграммы как SVG
3. Использование в документации

## 📊 Пример диаграммы

### Типичный процесс:
```
[Start] → [Задача 1] → [Шлюз?] → [Задача 2] → [End]
                    ↓
                 [Задача 3] → [End]
```

### Визуально:
- 🟢 Start (зеленый круг)
- 🔵 Задачи (синие прямоугольники)
- 🟡 Шлюз (желтый ромб)
- 🔴 End (красный круг)
- ➡️ Стрелки (связи)

## 🔧 Технические детали

### Генерация данных:
- AI создает структурированный JSON с элементами процесса
- Автоматическое определение порядка элементов
- Топологическая сортировка для правильного порядка

### Визуализация:
- SVG для векторной графики
- Адаптивное позиционирование элементов
- Цветовая кодировка по типам элементов
- Стрелки с метками условий

### Формат данных:
```json
{
  "process_name": "Название процесса",
  "start_event": {"id": "start", "label": "Начало"},
  "tasks": [
    {"id": "task1", "label": "Задача", "type": "task"}
  ],
  "gateways": [
    {"id": "gw1", "label": "Условие", "type": "exclusive"}
  ],
  "end_events": [
    {"id": "end", "label": "Конец"}
  ],
  "flows": [
    {"from": "start", "to": "task1", "label": ""}
  ]
}
```
