## 🎯 Возможности

1. **Предложения вариантов ответов** - AI предлагает 3-5 вариантов после каждого вопроса
2. **Автозаполнение из чата** - кнопка заполняет все поля BRD из диалога
3. **Автозаполнение из текста** - вставляете текст, AI заполняет поля
4. **Предложения Scope** - AI предлагает элементы scope для проекта
5. **Умное заполнение** - учитывает контекст и уже собранные данные

## 📍 Где использовать

- **В чате**: Предложения появляются автоматически
- **В панели BRD**: Кнопки "🤖 Автозаполнить" и "📝 Из текста"
- **Рядом с Scope**: Кнопка "🤖" для предложений элементов
