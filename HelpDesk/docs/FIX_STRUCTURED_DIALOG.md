# Исправление проблем структурированного диалога

## Проблемы, которые были исправлены:

### 1. Бот застревал на одном этапе
**Проблема**: Бот повторял один и тот же вопрос, не переходя к следующему этапу.

**Причина**: 
- PROJECT_NAME был отдельным этапом, хотя название проекта уже собирается на INITIAL
- Логика перехода между этапами была некорректной

**Решение**:
- Удален PROJECT_NAME из порядка этапов (STAGES_ORDER)
- После INITIAL сразу переходим к PROJECT_GOAL
- Улучшена логика определения следующего этапа

### 2. Неправильная обработка первого ответа
**Проблема**: Первый ответ пользователя не обрабатывался как название проекта.

**Решение**:
- Добавлена обработка INITIAL этапа в `_extract_data_from_answer()`
- Первый ответ теперь сохраняется как `project_name`

### 3. Слишком строгая проверка данных
**Проблема**: Требовалось минимум 10 символов, что было слишком много.

**Решение**:
- Для INITIAL этапа достаточно 3 символа
- Для обязательных этапов снижено до 5 символов

### 4. Логика перехода к REVIEW
**Проблема**: Не было четкой логики перехода к этапу REVIEW.

**Решение**:
- Добавлен метод `_is_ready_for_review()` для проверки готовности
- Автоматический переход к REVIEW когда собраны минимальные данные

## Изменения в коде:

1. **STAGES_ORDER** - удален PROJECT_NAME
2. **_extract_data_from_answer()** - добавлена обработка INITIAL
3. **_get_next_stage()** - улучшена логика перехода
4. **_has_sufficient_data()** - снижены требования к длине ответа
5. **_is_ready_for_review()** - новый метод для проверки готовности

## Порядок этапов теперь:

1. INITIAL - "Как называется ваш проект?" (название сохраняется)
2. PROJECT_GOAL - "Какова цель проекта?"
3. PROJECT_DESCRIPTION - "Опишите проект подробнее"
4. SCOPE_IN - "Что входит в scope?"
5. SCOPE_OUT - "Что НЕ входит в scope?"
6. BUSINESS_RULES - "Какие бизнес-правила?"
7. KPI - "Какие KPI метрики?"
8. LEADING_INDICATORS - "Какие лидирующие индикаторы?"
9. STAKEHOLDERS - "Кто stakeholders?"
10. CONSTRAINTS - "Какие ограничения?"
11. DEPENDENCIES - "Какие зависимости?"
12. REVIEW - Показ резюме и подтверждение
13. COMPLETE - Завершение и автоматическая генерация

## Тестирование:

Для проверки работы диалога:

1. Отправьте первое сообщение (например, "Создать безумный дизайн")
2. Бот должен:
   - Сохранить это как название проекта
   - Перейти к вопросу о цели проекта
   - НЕ повторять вопрос о названии

3. Ответьте на вопрос о цели (например, "Создать красивый интерфейс")
4. Бот должен перейти к следующему вопросу о описании проекта
