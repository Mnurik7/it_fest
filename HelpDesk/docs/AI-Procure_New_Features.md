# AI-Procure: Добавленные функции

## Дата обновления: 2025-01-03

Все различия из сравнения с требованиями задачи были реализованы и интегрированы в систему.

---

## ✅ Добавленные модули

### 1. **data_collector.py** - Сбор данных из открытых источников
**Приоритет:** 🔴 Критический

**Функциональность:**
- Сбор данных о тендерах из различных источников
- Генерация синтетических данных для тестирования
- Парсинг веб-страниц с информацией о тендерах
- Мониторинг новых тендеров с заданным интервалом
- Фильтрация собранных тендеров по различным критериям
- Поддержка пользовательских источников данных

**API Endpoints:**
- `POST /api/ai-procure/collect` - Сбор тендеров из источника
- `GET /api/ai-procure/collect/list` - Список собранных тендеров
- `POST /api/ai-procure/parse-web` - Парсинг веб-страницы

---

### 2. **price_analyzer.py** - Анализ цен и сравнение с рыночными
**Приоритет:** 🟡 Высокий

**Функциональность:**
- Анализ цен тендеров и сравнение с рыночными
- Выявление аномалий (завышенные/заниженные цены)
- Определение категории товара/услуги
- Сравнение с похожими тендерами
- Статистика по ценам по категориям
- Рекомендации на основе анализа цен

**API Endpoints:**
- `POST /api/ai-procure/analyze-price` - Анализ цены тендера
- `POST /api/ai-procure/compare-prices` - Сравнение с похожими тендерами
- `GET /api/ai-procure/price-statistics` - Статистика по ценам

---

### 3. **metrics_tracker.py** - Система метрик и аналитики
**Приоритет:** 🟡 Высокий

**Функциональность:**
- Отслеживание точности извлечения данных (target: ≥90%)
- Отслеживание времени обработки
- Статистика обнаружения рисков
- Метрики удобства использования (completion rate)
- Дневная статистика
- Обратная связь от пользователей
- Сохранение метрик в JSON файл

**API Endpoints:**
- `GET /api/ai-procure/metrics/performance` - Метрики производительности
- `GET /api/ai-procure/metrics/risks` - Метрики обнаружения рисков
- `GET /api/ai-procure/metrics/usability` - Метрики удобства использования
- `GET /api/ai-procure/metrics/daily` - Дневная статистика
- `POST /api/ai-procure/metrics/feedback` - Добавление обратной связи

---

### 4. **supplier_database.py** - База данных поставщиков
**Приоритет:** 🟡 Высокий

**Функциональность:**
- Добавление/удаление/обновление поставщиков
- Поиск поставщиков по критериям (специализация, местоположение, рейтинг, опыт)
- История участия в тендерах
- Статистика по поставщикам (win rate, количество проектов)
- Импорт поставщиков из списка
- Сохранение в JSON файл

**API Endpoints:**
- `POST /api/ai-procure/suppliers/add` - Добавление поставщика
- `POST /api/ai-procure/suppliers/search` - Поиск поставщиков
- `GET /api/ai-procure/suppliers/<supplier_id>` - Получение поставщика
- `GET /api/ai-procure/suppliers/<supplier_id>/statistics` - Статистика поставщика
- `GET /api/ai-procure/suppliers/list` - Список всех поставщиков

---

### 5. **document_parser.py** - Парсинг документов (PDF/Excel/CSV)
**Приоритет:** 🟢 Средний

**Функциональность:**
- Парсинг PDF документов (PyPDF2 и pdfplumber)
- Парсинг Excel файлов (xlsx, xls)
- Парсинг CSV файлов
- Парсинг текстовых файлов
- Автоматическое определение кодировки
- Извлечение структурированных данных из таблиц

**API Endpoints:**
- `POST /api/ai-procure/parse-document` - Парсинг загруженного документа
- `GET /api/ai-procure/supported-formats` - Список поддерживаемых форматов

## 🚀 Использование новых функций

### Пример: Сбор и анализ тендера

```python
# 1. Собрать тендеры из источника
POST /api/ai-procure/collect
{
    "source": "synthetic",
    "filters": {"count": 5}
}

# 2. Проанализировать тендер с новыми функциями
POST /api/ai-procure/analyze
{
    "tender_text": "...",
    "include_price_analysis": true
}

# 3. Проверить метрики
GET /api/ai-procure/metrics/performance
```

### Пример: Работа с поставщиками

```python
# 1. Добавить поставщика
POST /api/ai-procure/suppliers/add
{
    "supplier_data": {
        "name": "ООО Поставщик",
        "specialization": ["IT и программное обеспечение"],
        "rating": 4.5
    }
}

# 2. Найти подходящих поставщиков
POST /api/ai-procure/suppliers/search
{
    "criteria": {
        "specialization": "IT и программное обеспечение",
        "min_rating": 4.0
    }
}
```
