**HelpDesk AI Platform** - это комплексная платформа искусственного интеллекта для автоматизации поддержки клиентов и бизнес-процессов. Платформа объединяет специализированные Help Desk модули для различных отраслей, продвинутые AI-ассистенты для автоматизации задач и ML-модели для детекции мошенничества.

## 🎯 Основная цель проекта

**Полностью исключить участие 1 линии поддержки** и обеспечить **автоматическое распределение заявок** в профильные подразделения, а также **автоматизировать рутинные бизнес-процессы** с помощью искусственного интеллекта.

Проект разрабатывается в рамках **Hackathon ITFEST** как прототип интеллектуальной платформы нового поколения.

## ✨ Ключевые возможности

### 🎯 Help Desk Модули (6 отраслевых решений)

1. **IT Help Desk** - Техническая поддержка: решение проблем с оборудованием, ПО, настройками
2. **Medical Help Desk** - Медицинская поддержка: запись на приём, консультации, экстренные обращения
3. **Legal Help Desk** - Юридическая поддержка: консультации, обработка правовых запросов, документооборот
4. **Retail Help Desk** - Розничная поддержка: обработка жалоб, возвраты, консультации по товарам
5. **Telecom Help Desk** - Телекоммуникационная поддержка: проблемы со связью, интернетом, биллинг
6. **Auto Help Desk** - Автомобильная поддержка: техническая помощь, запись на сервис, консультации

### 🤖 AI-Ассистенты

1. **AI-Procure** - Интеллектуальный анализ тендеров и закупок
   - Извлечение параметров тендера из текста, PDF, веб-сайтов
   - Подбор поставщиков с оценкой соответствия
   - Анализ рисков и аффилированности
   - Генерация комплексных отчётов
   - Поддержка новичков с пошаговыми инструкциями

2. **AI-Scrum Master** - Цифровой Scrum Master
   - Управление проектами и командами
   - Создание задач из текста и транскриптов встреч
   - Интеллектуальная декомпозиция задач
   - AI-ассистент встреч (Stand-up, Grooming, Demo, Planning, Retrospective)
   - Контроль дедлайнов и управление спринтами
   - Аналитика и AI-инсайты

3. **AI-Business Analyst** - AI-помощник по бизнес-аналитике
   - Анализ документов (BRD, технические задания)
   - Структурированный диалог для сбора требований
   - Генерация BRD, FRD, Use Cases, User Stories, BPMN-диаграмм
   - Анализ процессов и предложения по улучшению
   - Интеграция с Confluence

4. **AI-Code Review Assistant** - Ревью кода с AI
   - Загрузка и анализ архитектуры проекта
   - Ревью отдельного файла и всего проекта
   - Анализ изменений (diff) в Merge Request
   - Управление статусами MR в GitLab
   - Обучающая поддержка для junior-разработчиков

5. **Fraud Detection** - ML-модели для детекции мошенничества
   - Анализ транзакций в реальном времени
   - Модели на основе XGBoost и LightGBM
   - Выявление подозрительных паттернов
   - MLOps Pipeline для обучения и развёртывания

## 🚀 Установка и запуск

### Основная платформа HelpDesk

1. **Установить Python версии не ниже 3.8:**
   ```bash
   python --version
   ```

2. **Клонировать репозиторий:**
   ```bash
   git clone https://github.com/Mnurik7/it_fest.git
   cd it_fest
   ```

3. **Создать виртуальное окружение:**
   ```bash
   # Windows
   python -m venv venv
   venv\Scripts\activate
   
   # Linux/Mac
   python3 -m venv venv
   source venv/bin/activate
   ```

4. **Установить зависимости:**
   ```bash
   cd HelpDesk
   pip install -r requirements.txt
   ```

5. **Создать файл `.env` в папке `HelpDesk/`:**
   ```env
   GEMINI_API_KEY=ваш_ключ_gemini
   GEMINI_MODEL=gemini-2.5-flash
   GEMINI_API_VERSION=v1beta
   FLASK_SECRET_KEY=ваш_секретный_ключ
   ```

6. **Запустить приложение:**
   ```bash
   python app.py
   ```

7. **Открыть в браузере:**
   ```
   http://localhost:5000
   ```

### Тестовые учетные данные:
- **Логин**: `admin` | **Пароль**: `admin123`
- **Логин**: `user` | **Пароль**: `user123`

### Telegram бот (опционально)

1. **Перейти в папку f1:**
   ```bash
   cd f1
   ```

2. **Установить зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Создать файл `.env`:**
   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен_бота
   GEMINI_API_KEY=ваш_ключ_gemini
   GEMINI_MODEL=gemini-2.5-flash
   GEMINI_API_VERSION=v1beta
   ```

4. **Запустить бота:**
   ```bash
   python bot.py
   ```

## 🔄 Принцип работы

### Help Desk модули:

1. **Пользователь отправляет обращение** через веб-интерфейс или Telegram
2. **Backend анализирует текст** через Gemini AI
3. **AI определяет категорию, приоритет и тип** запроса
4. **Если проблема типовая** - пользователю возвращается готовое решение (70-80% случаев)
5. **Если проблема сложная** - обращение автоматически передается профильному специалисту
6. **Вся информация сохраняется** в базе данных с историей диалогов
7. **Операторы работают** через веб-интерфейс с панелью управления

### AI-Ассистенты:

1. **Пользователь выбирает нужный AI-модуль** (Procure, Scrum, Business Analyst, Code Review)
2. **Загружает данные** (текст, документы, код, транскрипты)
3. **AI обрабатывает данные** и предоставляет структурированный анализ
4. **Генерируются отчеты, документы, рекомендации**
5. **Результаты сохраняются** и могут быть экспортированы

### Fraud Detection:

1. **Транзакции поступают** в систему в реальном времени
2. **ML-модели анализируют** паттерны и признаки мошенничества
3. **Выявляются подозрительные операции** с оценкой риска
4. **Генерируются алерты** для дальнейшей проверки
