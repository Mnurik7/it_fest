# AI Help Desk для АО Казахтелеком

AI Help Desk это интеллектуальный сервис поддержки пользователей с интеграцией Gemini AI.  
Система автоматизирует обработку обращений, маршрутизацию заявок и помогает службе технической поддержки работать быстрее и точнее.

Цель проекта: полностью исключить участие 1 линии поддержки и обеспечить автоматическое распределение заявок в профильные подразделения.

## Описание проекта

Сервис принимает обращения клиентов из различных каналов, анализирует текст с помощью искусственного интеллекта, определяет категорию, приоритет и тип проблемы, предлагает решение либо передает обращение в нужный департамент.

Проект разрабатывается в рамках Hackathon ITFEST как прототип интеллектуального Help Desk сервиса нового поколения для Казахтелекома.

## Установка и запуск

1. Установить Python версии не ниже 3.10
2. Создать виртуальное окружение:
   ```bash
   python -m venv venv
   venv\Scripts\activate  # Windows
   ```
3. Установить зависимости из requirements.txt:
   ```bash
   pip install -r f1/requirements.txt
   ```
4. Настроить файл `.env` в папке `f1/`:
   ```
   TELEGRAM_BOT_TOKEN=ваш_токен_бота
   GEMINI_API_KEY=ваш_ключ_gemini
   GEMINI_MODEL=gemini-2.5-flash
   GEMINI_API_VERSION=v1beta
   ```
5. Запустить backend сервер:
   ```bash
   cd f1
   python app.py
   ```
6. Запустить Telegram бота:
   ```bash
   cd f1
   python bot.py
   ```

## Переменные окружения

- `GEMINI_API_KEY` - API ключ для Gemini AI
- `FIREBASE_PROJECT_ID` - ID проекта Firebase (если используется)
- `TELEGRAM_BOT_TOKEN` - Токен Telegram бота

## Принцип работы

1. Пользователь отправляет обращение через Telegram, мобильное приложение или веб интерфейс
2. Сообщение передается в backend
3. Backend анализирует текст через Gemini AI
4. Определяется категория, приоритет и тип запроса
5. Если проблема типовая - пользователю возвращается готовое решение
6. Если проблема сложная - обращение передается инженеру
7. Вся информация сохраняется в базе данных
8. Операторы работают через веб интерфейс
