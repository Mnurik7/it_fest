# Карта медицинских учреждений Алматы

Веб-приложение на Flask для отображения карты города Алматы с медицинскими учреждениями (больницы, аптеки, клиники и т.д.) с использованием 2GIS API.

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` в корне проекта и добавьте ваши API ключи:
```
DGIS_API_KEY=ваш_ключ_2gis_api
TGIS_API_KEY=ваш_ключ_tgis_api
YANDEX_API_KEY=cf74351f-8cd8-4d19-864b-be2bd33c9b2c
```

**Примечание:** Yandex API ключ уже добавлен в код по умолчанию. Приложение будет использовать Yandex API в первую очередь для поиска организаций.

## Запуск

```bash
python app.py
```

Приложение будет доступно по адресу: http://localhost:5000

## Функционал

- 📍 Интерактивная карта Алматы с использованием 2GIS Maps API
- 🔍 Поиск медицинских учреждений по названию или адресу
- 🏥 Фильтрация по типам: больницы, аптеки, клиники, скорая помощь, стоматологии, ветеринарные клиники
- 📋 Список найденных объектов с возможностью перехода к маркеру на карте
- 🗺️ Автоматическое центрирование карты на найденных объектах

## API Endpoints

- `GET /` - Главная страница с картой
- `GET /api/search?q=запрос&type=тип&city=Алматы` - Поиск объектов
- `GET /api/types` - Список доступных типов объектов
