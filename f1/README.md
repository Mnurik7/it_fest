# AI Help Desk для Казахтелекома

Умная система поддержки клиентов на базе Telegram бота с интеграцией Gemini AI.

## Возможности

- 🤖 Автоматический анализ обращений клиентов
- 🧠 Распознавание категории проблемы с помощью AI
- 💡 Автоматическое предложение решений для простых проблем
- 👨‍💼 Автоматическая передача сложных обращений инженерам
- 📊 Хранение всех обращений в базе данных SQLite
- 📝 История диалогов для контекста

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Убедитесь, что файл `.env` создан и содержит все необходимые токены:
```
TELEGRAM_BOT_TOKEN=ваш_токен_бота
GEMINI_API_KEY=ваш_ключ_gemini
GEMINI_MODEL=gemini-2.5-flash
GEMINI_API_VERSION=v1beta
```

3. (Опционально) Сгенерируйте фейковые данные:
```bash
python3 generate_fake_data.py
```

4. Запустите бота:
```bash
python3 bot.py
```

## Структура проекта

- `bot.py` - основной файл бота с обработчиками команд и сообщений
- `gemini_client.py` - клиент для работы с Gemini AI API
- `database.py` - работа с базой данных SQLite
- `.env` - файл с токенами и настройками
- `requirements.txt` - зависимости проекта

## База данных

База данных SQLite (`kazakhtelecom.db`) содержит следующие таблицы:

### Основные таблицы:
- `users` - информация о пользователях Telegram
- `tickets` - обращения клиентов
- `engineers` - инженеры и их специализации
- `conversations` - история диалогов для контекста

### Таблицы клиентов и услуг:
- `clients` - клиенты Казахтелекома (ФИО, телефон, адрес, номер договора)
- `services` - услуги клиентов (тарифы, статус, блокировки, долги)
- `requests` - заявки клиентов (история обращений)

### Таблицы сети:
- `network_segments` - сегменты сети (районы, улицы, диапазоны домов, узлы)
- `outages` - аварии на сети (активные и завершенные)

## Генерация фейковых данных

Для заполнения базы данных фейковыми данными по Казахстану:

```bash
python3 generate_fake_data.py
```

Скрипт создаст:
- 200 клиентов из разных городов Казахстана
- 300 сегментов сети
- Активные и завершенные аварии
- Заявки и услуги

После генерации бот сможет:
- Определять клиента по telegram_id
- Проверять адрес и сегмент сети
- Предупреждать об авариях в районе клиента
- Проверять услуги и задолженности

## Команды бота

- `/start` - начать работу с ботом
- `/help` - справка по использованию
- `/my_tickets` - посмотреть свои обращения

## Как это работает

1. Клиент отправляет сообщение с описанием проблемы
2. Бот анализирует проблему с помощью Gemini AI
3. AI определяет категорию проблемы и предлагает решение
4. Если проблема простая - бот предлагает решение
5. Если проблема сложная - обращение автоматически передается инженеру
6. Все обращения сохраняются в базе данных

## Категории проблем

- Интернет (скорость, подключение, настройки)
- Телефония (звонки, настройки)
- Телевидение (каналы, качество сигнала)
- Оборудование (модемы, роутеры, приставки)
- Оплата (счета, платежи, тарифы)
- Другое
