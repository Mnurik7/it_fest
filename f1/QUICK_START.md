# Быстрый старт

## Шаг 1: Установка зависимостей
```bash
python3 -m pip install -r requirements.txt
```

## Шаг 2: Генерация фейковых данных (уже выполнено)
```bash
python3 generate_fake_data.py
```

База данных уже содержит:
- ✅ 200 клиентов из разных городов Казахстана
- ✅ 300 сегментов сети
- ✅ Активные и завершенные аварии
- ✅ Заявки и услуги

## Шаг 3: Запуск бота
```bash
python3 bot.py
```

## Как протестировать

### Вариант 1: Использовать существующего клиента
В базе есть клиенты с telegram_id от 1000000000 до 1000000199.
Если ваш telegram_id совпадает с одним из них, бот автоматически:
- Определит ваш адрес
- Проверит услуги
- Найдет аварии в вашем районе

### Вариант 2: Добавить себя как клиента
Можно добавить свой telegram_id в базу через SQL или создать скрипт.

### Примеры сообщений для тестирования:
- "Нет интернета"
- "Низкая скорость интернета"
- "Не работает телевидение"
- "Проблемы с телефоном"
- "Хочу узнать свой тариф"

## Как работает система

1. **Клиент пишет боту** → Бот проверяет telegram_id в базе клиентов
2. **Если клиент найден** → Бот получает:
   - Адрес клиента
   - Услуги и тарифы
   - Проверяет сегмент сети
   - Ищет активные аварии в районе
3. **AI анализирует** → С учетом всей информации о клиенте
4. **Бот отвечает** → С учетом аварий, услуг, адреса

## Пример работы

**Клиент:** "Нет интернета"

**Бот анализирует:**
- Находит клиента по telegram_id
- Определяет адрес: Алматы, Абая, д. 12
- Находит сегмент: Алматы-Алмалинский-Узел1
- Проверяет аварии: "⚠️ В вашем районе активна авария! Восстановление до 14:00"

**Результат:** Бот сразу сообщает об аварии, не требуя уточнений!
