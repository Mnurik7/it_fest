# Веб-приложение Казахтелеком

Веб-интерфейс для системы поддержки клиентов Казахтелекома.

## Возможности

- 🔐 Авторизация по номеру телефона и паролю
- 📝 Регистрация новых клиентов
- 💬 Создание обращений с помощью AI (Gemini)
- 📊 Просмотр услуг и заявок
- ⚠️ Уведомления об авариях в районе
- 🔧 Пошаговая диагностика проблем
- 👨‍💼 Автоматическое создание заявок для инженеров

## Установка и запуск

1. Убедитесь, что установлены все зависимости:
```bash
pip install -r requirements.txt
```

2. Убедитесь, что файл `.env` содержит необходимые токены:
```
TELEGRAM_BOT_TOKEN=ваш_токен_бота
GEMINI_API_KEY=ваш_ключ_gemini
GEMINI_MODEL=gemini-2.5-flash
GEMINI_API_VERSION=v1beta
FLASK_SECRET_KEY=ваш_секретный_ключ
```

3. Запустите веб-приложение:
```bash
python app.py
```

4. Откройте браузер и перейдите по адресу:
```
http://localhost:5000
```

## Структура проекта

- `app.py` - основное Flask приложение
- `templates/` - HTML шаблоны
  - `base.html` - базовый шаблон
  - `login.html` - страница входа
  - `register.html` - страница регистрации
  - `dashboard.html` - главная страница клиента
  - `tickets.html` - страница с обращениями
- `static/css/` - стили CSS
  - `style.css` - основные стили в корпоративном стиле Казахтелекома
- `static/js/` - JavaScript файлы
  - `main.js` - основные утилиты
  - `dashboard.js` - логика для dashboard

## Использование

### Регистрация
1. Перейдите на страницу регистрации
2. Заполните все обязательные поля:
   - ФИО
   - Номер телефона
   - Пароль (минимум 6 символов)
   - Город, улица, номер дома
   - Номер договора (лицевой счет)
3. Нажмите "Зарегистрироваться"

### Вход
1. Введите номер телефона и пароль
2. Нажмите "Войти"

### Создание обращения
1. На главной странице (dashboard) введите описание проблемы
2. Нажмите "Отправить"
3. Система автоматически:
   - Проверит аварии в вашем районе
   - Проанализирует проблему с помощью AI
   - Предложит решение или создаст заявку

## База данных

Веб-приложение использует ту же базу данных SQLite (`kazakhtelecom.db`), что и Telegram бот, обеспечивая единую систему управления обращениями.

## API Endpoints

- `GET /` - главная страница (редирект на login или dashboard)
- `GET /login` - страница входа
- `POST /login` - обработка входа
- `GET /register` - страница регистрации
- `POST /register` - обработка регистрации
- `GET /dashboard` - главная страница клиента
- `GET /tickets` - страница с обращениями
- `POST /create_ticket` - создание обращения (JSON API)
- `POST /diagnostic_step` - обработка шага диагностики (JSON API)
- `GET /logout` - выход из системы
